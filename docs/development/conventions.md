# Conventions

Phase 0 keeps the starter kit's tooling as-is rather than introducing
LaraDogs-specific conventions ahead of having LaraDogs-specific code to
apply them to.

## PHP

- **Style**: [Laravel Pint](https://laravel.com/docs/pint), configured via
  `pint.json` (starter-kit default preset).
    ```bash
    composer lint         # fix
    composer lint:check   # check only, no changes (used in CI/`composer test`)
    ```
- **Static analysis**: [Larastan](https://github.com/larastan/larastan)
  (PHPStan with Laravel-aware rules), configured via `phpstan.neon`.
    ```bash
    composer types:check
    ```
- **Tests**: Pest — see [`testing.md`](testing.md).

## TypeScript / React

- **Lint/format**: `npm run check` (and `npm run check:fix` to
  auto-fix), via `vp check` (`vite-plus`'s bundled ESLint/Prettier
  integration).
- **Types**: `npm run types:check` (`tsc --noEmit`).
- Components follow the starter kit's structure: `pages/` (one per Inertia
  route), `layouts/`, `components/` (with shadcn primitives isolated under
  `components/ui/`), `hooks/`, `lib/`. See
  [`../architecture/components.md`](../architecture/components.md).
- Don't hand-write route URLs in TypeScript — use the generated Wayfinder
  helpers (`resources/js/actions`, `resources/js/routes`), regenerated by
  `npm run build` / `npm run dev`.

## Commits and scope

- Code, identifiers, comments, and commit messages are in **English**,
  regardless of the language used in project discussions/planning docs.
- Avoid scope creep: a change belonging to a later roadmap phase (see
  [`../roadmap/phases.md`](../roadmap/phases.md)) should be proposed there,
  not folded into an unrelated change.

## One command for "is this change safe to merge"

```bash
composer run test   # config:clear -> Pint check -> Larastan -> Pest
npm run check
npm run types:check
```

This is exactly what CI runs: `.github/workflows/tests.yml` (starter-kit
default, PHP 8.3 + Node 22 on `ubuntu-latest`) runs `composer setup` then
`composer ci:check` (`npm run check` + `npm run types:check` + `@test`) on
every push to `main` and every pull request. `.github/dependabot.yml`
(also starter-kit default) keeps Composer/npm/Actions dependencies
updated. Neither file has been modified from what the installer
generated.
